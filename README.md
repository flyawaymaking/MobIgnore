# MobIgnore

MobIgnore — лёгкий плагин для Minecraft 1.21+ (Paper), который позволяет игрокам временно отключать агрессию мобов по отношению к себе. Идеально для строительства, исследования или просто спокойной игры.

---

## Возможности

- **Временное игнорирование** - мобы перестают атаковать игрока
- **Мгновенное действие** - эффект применяется сразу после команды
- **Сброс целей** - все текущие атаки мобов на игрока прекращаются
- **Лёгкий вес** - минимальное влияние на производительность сервера

---

## Использование

Просто введите команду:

```text
/mobignore
```

**При первом использовании:**
```text
Теперь мобы будут тебя игнорировать!
```

**При повторном использовании:**
```text
Мобы снова могут нападать на тебя.
```

> Команда переключает режим "игнора" - при каждом использовании эффект меняется на противоположный.

### Конфиг

```yml
# Радиус очистки целей мобов
target-clear-radius: 32

messages:
  player-only: "<red>Эта команда только для игроков!"
  no-permission: "<red>У тебя нет прав использовать эту команду."
  enabled-mobs-attack: "<yellow>Мобы снова могут нападать на тебя."
  ignore-enabled: "<green>Теперь мобы будут тебя игнорировать!"
```

---

## Как это работает

- При активации все мобы в радиусе **32 блоков** (настраивается) теряют цель на игрока
- Новые мобы не могут выбрать игрока как цель для атаки
- Эффект работает только на мобов (зомби, скелеты, криперы и т.д.)
- Игроки могут атаковать друг друга как обычно

---

## Команды и права

- `/mobignore` - переключить режим игнорирования мобов

**Права:**
- `mobignore.use` - разрешает использовать команду (по умолчанию: op)

---

## Требования

- Minecraft Paper 1.21+
- Java 21

---

## Установка

1. Скачайте **последний релиз** из раздела [Releases](../../releases)
2. Поместите файл в папку `/plugins/`
3. Перезапустите сервер
4. Настройте `config.yml` при необходимости
5. Готово! Игроки с правом `mobignore.use` могут использовать `/mobignore`

---

## Для администраторов

Плагин не требует настройки и работает "из коробки". Все игроки с правом `mobignore.use` могут использовать команду.
